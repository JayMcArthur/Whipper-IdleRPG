This wiki's public table snapshot comes from Android **7.3.1, build 142**. Newer screens and modes do not necessarily add a new row to every catalog, so an unchanged equipment table is not proof that the whole game works exactly as before.

## Multiple slots

The game supports up to three save slots. Check which slot you have selected before following progression advice or comparing equipment. A local wiki build or item-book entry is not automatically associated with one of those slots.

The official version history introduced the three-slot feature in 7.0.0. Platform release histories can differ; this wiki records the Android version it actually captured.

## Kaiser Mode

The official release notes describe Kaiser Mode as content unlocked through scenario progress. The current game text says Kaiser becomes selectable when starting a new game after it is unlocked.

The current [Combat Data material](../../materials/200/) has a mode-related description: it records defeated monsters' experience and converts it into experience at the result screen. Read the localized in-game description for the wording used by your language.

Precise mode-specific combat formulas, unlock conditions and progression rules are not established by that description alone. Advice for an ordinary adventure should not be presented as a guaranteed Kaiser strategy.

## Ability extraction and bulk synthesis

Official history records ability extraction during analysis and bulk ability synthesis in 6.4.1. Later controls include matching filters and an option to hide bulk synthesis.

Read the current operation preview before committing important equipment. Changes in a synthesis interface are a reason to check a recipe, not to assume every older instruction still applies.
