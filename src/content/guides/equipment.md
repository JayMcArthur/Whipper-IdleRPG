A build is a weapon, armor and ring working toward a goal. Start with the next dungeon or enemy you want to beat, then decide which equipment helps. A theoretical best item is less useful than an improvement you can actually make.

## Compare the whole item

The [weapon](../../weapons/), [armor](../../armor/) and [ring](../../rings/) references show base properties. Your individual copy can differ through upgrades, corrosion, rarity, analysis and abilities.

Check both starting stats and level-up gains. Consider the ability slots and set partner, not just the first large number on the item screen. Compare the item's actual in-game details before replacing something that already works.

## Upgrade and evolution

Upgrading improves equipment using materials. The app shows the applicable limit and cost. The wiki's **base upgrade limit** is the value in the item definition; analysis and later progress can change the effective limit for your copy.

Some items evolve as you strengthen them. Follow **Evolves into** on an equipment page to explore the recorded chain. It is a relationship in the base data, not a promise that any current copy meets every condition right now.

## Sets

A set pairs compatible equipment. The reference links listed partners using their game identities, so changing the interface language does not change the pairing.

Read the actual set effect in the app. A named set does not make every setup better: an item with a useful standalone effect or more appropriate stats may fit a particular opponent better.

## Abilities and enchantments

Some abilities add starting stats; others improve growth, modify probabilities or introduce an effect such as poison. Use the [ability reference](../../enchantments/) to compare the game's descriptions and recorded levels.

Do not assume that two abilities stack, that a displayed value is already a final chance, or that a boss follows ordinary-monster rules. Exact combat interactions are separate from the ability catalog.

## Corrosion and analysis

These systems can make an otherwise familiar item much stronger or reveal further effects. Analysis and corrosion requirements can interact. Use the equipment and analysis screens together rather than reading a threshold in isolation.

See [analysis and permanent progress](../analysis/) for the distinction between the item you equip and your item-book progress.

## Synthesis

Later versions support ability extraction during analysis and bulk ability synthesis. The newer synthesis controls include matching filters and an option to hide bulk synthesis. Read the in-game preview carefully before consuming or combining items.

Do not use an old universal synthesis recipe if it conflicts with the current app's preview. Keep important equipment until you understand what a particular operation retains or consumes.

## A practical comparison

1. Choose the target dungeon or enemy.
2. Keep the pieces that already solve its main threat.
3. Compare one replacement with the current item, including abilities and set effects.
4. Check whether the improvement is available with your current materials and progress.
5. Try it and read the result.

The existing [Build Maker](../../tools/) can store local ideas, but it is experimental. A larger calculated power score does not establish that a build is legal for your inventory or better against a particular boss.
