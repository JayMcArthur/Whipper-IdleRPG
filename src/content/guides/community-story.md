        <h3>The Illusory Royal Tomb</h3>
        <p>Unlocks when you gain access to M1. You start with floors 1-50. Each time you clear the final floor, you gain access to the next set of 50.</p>
        <p><strong>Loot schedule (repeating every 50 floors):</strong></p>
        <p>Every 50n+10, 50n+30: Rosetta Stone (+10 analysis)</p>
        <p>Every 50n+20: HardenerZG (+50 upgrade value)</p>
        <p>Every 50th floor: Black Key (for Fallen Junkyard)</p>
        <p>Every 300th floor: Illusory Ore Whetstone (+10 corrosion)</p>
      </div>

      <div>
        <h3>Fallen Junkyard</h3>
        <p>After obtaining the Core Fragment (M2 unlocked), obtain a Black Key from The Illusory Royal Tomb. Keys drop every 50th floor.</p>
        <p>See the <a href="../../bosses/">Bosses page</a> for detailed boss info.</p>
      </div>

      <div>
        <h3>The Door to Another World</h3>
        <p>Can lead to several dungeons depending on what code you enter. Some dungeons are the only source of powerful equipment.</p>
        <p>To progress the story, you need to enter the code:</p>
        <div>
          <details>
            <summary>Reveal story code (spoiler)</summary>
            <code>wonderland</code>
          </details>
        </div>
        <p>If you want to find it yourself, explore the previous dungeons again. Check the end of the dungeon log for clues.</p>
        <p>The Door also accesses semi-random dungeons. Entering any other code generates a random dungeon. Each code maps to exactly 1 dungeon. The game saves the 10 most recent codes.</p>
        <p>See the <a href="../../dungeons/">Dungeons page</a> for recommended keys.</p>
      </div>

      <div>
        <h3>Alchemist's Island</h3>
        <p>Accessed with a Map Fragment from the daily bonus chest. Three floors, each with specific materials:</p>
        <p>1F [50min]: G-level hardeners</p>
        <p>2F [50min]: All essences (silver, gold, star)</p>
        <p>3F [50min]: Illusory Ore Whetstone only</p>
